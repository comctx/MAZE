# MAZE™

**Find Your Way Out**

MAZE™ is an endlessly generated maze game with multiple difficulty levels, special challenge modes, sound effects, flashlight gameplay, and both overhead and straight-on views.

Every new maze is different.

## 🎮 Maze Modes

- Classic Maze
- 🔑 Keys & Doors
- 🧠 Memory Maze
- 🌀 Portal Maze
- 🎯 Two Dots
- 💎 Treasure Hunt
- 🧱 Moving Walls
- ⚠️ Trap Tiles
- 🧊 Ice Maze
- 👻 Ghost Chase
- ⏰ Countdown Escape
- 🪙 Coin Challenge
- 🪞 Mirror Controls
- ➡️ One-Way Arrows
- ❓ Mystery Mode

## 👀 View Modes

Play MAZE from several perspectives:

- 🗺️ Overhead View
- 👀 First-Person View
- 🧱 Dungeon View
- 🌌 Neon View

First-person modes let you move through the maze as if you are standing inside it.

## 🔦 Flashlight Mode

Turn on Flashlight Mode to limit how much of the maze you can see.

In straight-on views, the flashlight illuminates the corridor directly ahead.

## 🔊 Sound Effects

MAZE includes built-in sound effects for:

- Player movement
- Keys
- Doors unlocking
- Correct and wrong mystery dots
- Portals
- Gems and coins
- Traps
- Moving walls
- Ghost encounters
- Countdown warnings
- Victory celebrations

Sound can be turned on or off at any time.

## 🏁 Difficulty Levels

- Easy
- Medium
- Hard
- Extreme

## 📅 Daily Maze

Daily Maze creates a repeatable maze for the current day so players can try to improve their time and number of steps.

## 🏆 Scoring

MAZE tracks:

- Time
- Steps
- Best completion time

Best scores are saved on the device.

## 🎆 Victory

Reach the exit and MAZE celebrates with a victory message, sound, and fireworks display.

## 🖥️ Controls

### Overhead View

**Computer**
- Arrow Keys
- W A S D
- Mouse

**Touchscreen**
- Drag your finger through the maze

### Straight-On Views

**Computer**
- Up / W — Move Forward
- Down / S — Move Back
- Left / A — Turn Left
- Right / D — Turn Right

**Touchscreen**
- Use the on-screen controls
- Swipe to turn or move

## 🌐 Technology

MAZE is built with:

- HTML
- CSS
- JavaScript
- HTML5 Canvas
- Web Audio API

No external game engine is required.

MAZE is designed to work on:
